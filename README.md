# Year 12–13 IB Diploma Spanish B (SL & HL)

> **Provisional: aligned to FA2029 subject brief; full guide due Feb 2027**

Interactive Year 12–13 IB Diploma **Spanish B** (post-IGCSE B1 → B2/C1 — **not** *ab initio*) study guide, grammar & text-type mastery lab, procedural skill drills, timed mock papers, Individual Oral (IO) workbench, and dedicated **1,000+ item B1–C1 Vocab & Verb Hub** (`/vocab`) with `es-ES` Web Speech audio and on-screen Spanish accent keypad (`á é í ó ú ñ ü ¿ ¡`).

1. **`1-identidades`** — Theme 1: *Identidades* (SL + HL)
2. **`2-experiencias`** — Theme 2: *Experiencias* (SL + HL)
3. **`3-ingenio-humano`** — Theme 3: *Ingenio humano* (SL + HL)
4. **`4-organizacion-social`** — Theme 4: *Organización social* (SL + HL)
5. **`5-compartir-el-planeta`** — Theme 5: *Compartir el planeta* (SL + HL)

7. **`7-paper1-paper2-skills`** — Paper 1 Writing & Paper 2 Reading/Listening Mastery (SL + HL)
8. **`8-hl-literature`** — HL Literature & ~300-Word Literary Extract Analysis (**HL Only** — zero prescribed set texts; all named works tagged `[Example work — not a set text]`)

## Features
- **Dedicated `/vocab` Hub:** 1,000+ post-IGCSE B1–C1 vocabulary items across all 5 Prescribed Themes + HL Literary Terms + Irregular/Subjunctive Verb Tables, with Web Speech `es-ES` (`🔊` normal + `🐢` slow) audio, theme/level search & filter, and flashcard quiz mode.
- **Spanish Accent Keypad & Gentle Diacritic Forgiveness:** On-screen `á é í ó ú ñ ü ¿ ¡` keypad under every text answer box, plus `"close"` feedback on missing accents/ñ while keeping exact Spanish orthography required for full credit.
- **Zero-Login Local iPad Persistence:** Works offline-first via `localStorage` (`y12spanishb`), with optional family cloud sync via Vercel Blob.
- **Full Verification Gate:** `npm ci`, `npm audit --omit=dev` (0 high/critical), `typecheck`, `eslint`, `npm test`, `npm run validate`, 100% blind-solver audit, `next build`, and Playwright 390/820 px zero-overflow verification.
